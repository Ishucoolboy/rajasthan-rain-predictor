Sources & coverage

IMD: official district warnings/nowcast feeds. Open-Meteo: ECMWF, GFS, ICON and AIFS model access. RainViewer: observed radar history.

Rainbow minute-level nowcast can be added with a server-side API key. Windy, Ventusky, WunderMap and Zoom Earth are reference products; this app does not scrape or copy their proprietary layers.

Forecasts are estimates. Radar observations and numerical-model forecasts answer different questions. A universal 95% accuracy guarantee is not scientifically honest; this dashboard exposes model agreement and prepares the data needed for measured verification.
